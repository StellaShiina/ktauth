访问策略

通过 IP 黑白名单控制边界，让可信来源快速通过，异常来源及时阻断。

03

精确限速

按来源约束请求频率，并对持续滥用行为自动追加临时保护。

04

两种注册方式

按场景选择邀请 Token 或邮箱验证码，验证码邮件开箱即用。

05

会话管理

使用安全密码哈希与可撤销会话，在轻量和可控之间取得平衡。

06

自托管

数据留在自己的基础设施中，通过容器快速部署并独立运行。
